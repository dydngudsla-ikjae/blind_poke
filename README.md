# 개체 식별 터미널 — 블라인드 포켓몬 (추리 코어 MVP)

가려진 포켓몬을 단서를 조회해 정체를 맞히는 추리 게임. 블라인드삼국의 "가명 + 정체 추리"를 포켓몬으로 옮긴 코어 루프.

## 실행

`fetch`로 데이터를 읽으므로 로컬 서버로 띄워야 함(더블클릭 X):

```bash
npm install
npm run dev   # → http://localhost:5175 (http-server)
```

스프라이트는 github(raw.githubusercontent.com)에서 불러오므로 브라우저에 인터넷 연결 필요.

## 구조

```
blind-pokemon/
├── index.html
├── style.css        분석 터미널 테마(조사) + 초원/흙바닥 부지 테마(본거지)
├── data.js          공용 데이터 로드 · 유틸(타입 색상, fetch 등)
├── game.js          부트스트랩(데이터 로드 → 첫 화면 진입)
├── identify.js       문제 생성(스타팅 드래프트 포함) · 단서 조회 · 식별 판정
├── base.js           본거지: 로스터 · 자원 · 직무 배정 · 턴 진행 · 부지 씬
├── assets/
│   ├── grass-bg.svg  본거지 배경 — 절차적으로 생성한 초원 텍스처
│   └── dirt-bg.svg   부지(plot) 배경 — 절차적으로 생성한 흙바닥 텍스처
└── data/
    ├── pokemon.json 1025종 (기존 데이터 + 키/몸무게 병합됨)
    ├── type.json     타입 id→이름
    ├── move.json     기술 id→이름
    └── ability.json  특성 id→이름
```

## 정보 공개 설계 (지금 구현된 것)

- **최초 공개(상시):** 타입 1개(후보 선정 화면에서 이미 봤던 타입), 키(m), 몸무게(kg)
  - 두 번째 타입 유무 및 종류는 비공개 상태로 시작 — "박사와 상담하기"로만 확인 가능.
- **대화(조회):**
  - 박사와 상담하기 → 아래 5종 중 하나를 **가중 랜덤**으로 공개. **반복 가능**(매번 다시 뽑음).
    - 능력치(3) → 가장 높은 **종족값** 계열 (수치 비공개). ※IV가 아니라 종족값 — 종을 특정하는 정보라서.
    - 색상(3) → 아트워크를 48×48로 다운스케일해 배경/외곽선을 제외한 대표 색상 3개 추출.
    - 기술(3) → 배울 수 있는 기술 목록 중 무작위 1개.
    - 두 번째 타입(3) → 먼저 두 번째 타입의 **존재 여부**를 공개, 이미 존재를 안 상태라면 다음번엔 **구체적인 타입**을 공개(2단계 확률적 공개). 단일 타입 개체는 "두 번째 타입 없음"으로 확정.
    - 특성(1) → 특성 후보 중 무작위 1개. 다른 후보들보다 확률 낮게(가중치 1) — 정보량이 커서 희귀 취급.
  - 직접 관찰하기 → 공식 아트워크의 ~5px 조각을 확대(색·질감). **이번 개체당 1회**, 다음 개체에서 다시 가능.
- **본인확인서:** 실루엣 대조(최종 단서)
- 식별 입력은 자유 텍스트(자동완성 없음).

## 본거지 (지금 구현된 것)

- **부지:** 초원 배경(`assets/grass-bg.svg`) 위에 흙바닥 부지 칸(`assets/dirt-bg.svg`)을 직무 배정 인원 상한(`plotCap`)만큼 배치. 처음엔 **1칸(빈 공터)**에서 시작하고, "땅 평탄화" 직무로 칸이 늘어남. 직무가 배정된 개체는 부지 칸에 스프라이트로 설치되어 보임 — 클릭하면 해당 로스터 카드로 스크롤.
- **우호도:** 포획 시 개체별 상한(전설/환상은 낮게)에서 시작하지만, 사탕을 먹여 **레벨업할 때마다 상한이 +3씩 올라 최종적으로 100까지** 채울 수 있음.
- **특수능력:** 포획 시 0~100 랜덤으로 부여되는 개체별 재능치. 직무 산출량 계산에 배율(0.5~1.5배)로 반영되어 **작업 능력치**로 환산됨.

## 구현 노트

- **CORS:** 실루엣은 CSS `filter:brightness(0)`, 표본 패치는 `drawImage` 크롭(픽셀 read 없음)으로 처리해 원천적으로 무관. 색상 힌트는 `raw.githubusercontent.com`이 `Access-Control-Allow-Origin: *`를 보내주는 걸 이용해 `img.crossOrigin="anonymous"` + `getImageData`로 픽셀을 직접 읽음.
- 가명은 순수 노이즈(정답 이름과 충돌 시 재생성).
- 상담 가중치(능력치/색상/기술/두 번째 타입 3, 특성 1)는 `identify.js`의 `consultProfessor()` 안 `pool` 배열에서 조정.
- `assets/*.svg`는 외부 이미지 라이선스 문제 없이 매 실행 시 그대로 재사용되는 정적 SVG — 절차적으로 생성해 한 번 저장해둔 것(런타임에 재생성하지 않음).
