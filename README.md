# BlindPoke

정체를 숨긴 포켓몬을 단서로 식별하고, 동료로 포획해 본거지를 건설·운영하는 브라우저 게임입니다.

## 현재 게임 흐름

현재 플레이 루프는 다음 순서로 연결됩니다.

1. 숲 공터의 나무 표지에서 세 기척을 살피고 종이 수첩의 단서를 읽어 포켓몬 3마리를 영입한다.
2. 본거지에서 포켓몬을 관리하고, 빈 부지에 건물을 착공하거나 다음 턴을 진행한다.
3. 탐험에서 미확인 개체를 선택하고 단서를 사용해 정체를 추리한다.
4. 이름을 정확히 맞히면 남은 우호도를 확률로 사용해 포획을 시도한다.
5. 포획한 포켓몬을 성장시키고 전투 엔트리에 등록한다.
6. 지도에서 인접 지역에 도전해 포켓몬 배틀로 영토를 확보한다.
7. 확보 지역의 수입과 건설 진행을 바탕으로 본거지를 확장한다.

게임 상태는 주요 행동 직후 브라우저 `localStorage`에 자동 저장됩니다. 스타팅 선택이나 트레이너 공개 도중에 새로고침하면 해당 단계에서 이어지고, 공개를 마친 뒤에는 본거지에서 시작합니다. 트레이너 스프라이트의 출처는 [크레딧](./assets/trainers/CREDITS.md)에서 확인할 수 있습니다.

## 현재 적용된 게임 정책

### 턴과 행동 에너지

- 한 턴의 최대 행동 에너지는 5입니다.
- `다음 턴`을 누르면 에너지가 5로 회복됩니다.
- 탐험이나 거점 도전에 행동력이 부족하면 해당 화면에서 자금 5로 충전권을 살 수 있습니다. 구매 시 행동력이 최대 2 회복됩니다. 다음 턴 수입과 구매 전후 잔액은 상점에서 비교할 수 있습니다.
- 탐험은 에너지 2, 건물 착공은 에너지 1을 소비합니다.
- 공사 중인 건물에 인력을 추가하는 행동은 인원수와 관계없이 에너지 1을 소비합니다.
- 지도에서 지역 공격을 시작하면 에너지 2를 소비합니다.
- PC에서 먹이, 경험치 사탕, 기술 지도를 사용할 때 각각 에너지 1을 소비합니다.

### 건설

- 본거지에는 부지가 10개 있으며, 현재 개방된 부지만 사용할 수 있습니다.
- 건물 한 채가 부지 한 칸을 차지하고 같은 종류의 건물을 여러 채 지을 수 있습니다.
- 건물은 밭, 레스토랑, 훈련소, 제작소, 치료소의 5종입니다.
- 기본 건설 기간은 3턴입니다.

| 건설 인력 | 완공 기간 |
|---:|---:|
| 1마리 | 3턴 |
| 2마리 | 2턴 |
| 3마리 이상 | 1턴 |

- 착공 직후에는 시간이 흐르지 않고, 다음 턴부터 남은 기간이 감소합니다.
- 인력이 한 마리도 없으면 공사가 일시정지됩니다.
- 인력을 추가해도 이미 단축된 남은 시간이 다시 늘어나지 않습니다.
- 인력 회수와 공사 취소가 가능하며, 소비한 에너지는 환불되지 않습니다.
- 완공된 건설 인력은 해당 건물의 대기 인력으로 남습니다.
- 건설 창에서 현재 행동력과 착공·추가 배치 비용, 선택한 인력으로 걸리는 공사 기간과 한 마리 더 투입했을 때의 단축량을 확인할 수 있습니다.

### 타입별 전용 직무

완공된 시설에서 필요한 타입의 포켓몬을 배치합니다. 복합 타입은 두 타입의 직무를 맡을 수 있습니다. 같은 시설 내 배치와 회수는 행동력 0이고, 처음 배치하거나 다른 시설에서 이동하면 행동력 1입니다. 한 마리는 건설, 직무, 개척 중 한 곳에만 배치할 수 있으며 전투 엔트리 등록은 병행할 수 있습니다.

| 시설 | 지원 직무 |
|---|---|
| 밭 | 풀은 씨앗 생성, 물은 씨앗으로 열매 재배, 벌레는 작업자당 해당 밭 열매 생산량 +20% |
| 레스토랑 | 불꽃은 열매로 음식 조리, 얼음은 다음 턴 저장 상한 +10 |
| 훈련소 | 격투는 기술머신 생산, 에스퍼는 경험치 사탕 생산 |
| 제작소 | 바위는 재료 채취, 강철은 재료로 자금 주조, 전기는 재료로 부품 제작 |
| 치료소 | 페어리는 우호도 회복 아이템, 독은 배틀 상태이상 치료 아이템 생산 |

본거지는 부지 한 곳으로 시작합니다. 다음 미개척 부지에 땅 타입을 행동력 1로 배치하면 다음 턴에 부지를 열고 작업자가 돌아옵니다. 최대 10곳을 열 수 있습니다. 시설에서는 직무에 맞는 타입의 포켓몬을 찾거나 증원할 수 있습니다. 부지를 열 땅 타입이 부족할 때도 같은 탐험을 사용합니다. 행동력 2를 쓰면 해당 타입의 일반 후보가 포함됩니다.

레벨, 시설 특수능력, 지닌 도구가 생산량에 반영됩니다. 정수 수량을 지급하고 소수점은 작업자와 직무별로 다음 턴에 넘깁니다. 선행 생산물은 같은 턴에 사용할 수 있고, 재료나 저장 공간 때문에 막힌 생산분은 쌓이지 않습니다. 시설에서 배치 전후 인원, 실제 산출, 재료 사용과 이동 전 시설의 차이를 확인할 수 있습니다. 다음 턴 공동 재고가 얼마나 달라지는지와 함께 영향을 받는 시설도 배치 전에 확인할 수 있습니다.

### 탐험, 식별, 포획

- 탐험 한 번에 미확인 포켓몬 후보 3마리가 나타납니다.
- 박사 상담은 능력치, 기술, 특성, 타입 순으로 새 단서를 제공하고, 남아 있는 기술·특성 단서는 이후 상담에서 확인할 수 있습니다.
- 관측경에서 본 감지 타입·키·몸무게는 식별 일지에서도 확인할 수 있습니다.
- 본인확인서 대조는 외곽 실루엣을 보여줍니다. 박사 상담이나 실루엣 대조로 단서를 얻을 때마다 우호도가 8 감소하고, 열어 본 단서는 기록에서 다시 확인할 수 있습니다.
- 이름을 틀릴 때마다 우호도가 20 감소합니다.
- 우호도는 개체별 최저치 아래로 내려가지 않습니다.
- 이름을 정확히 맞힌 시점의 우호도가 최종 포획 성공 확률이 됩니다.
- 포획에 실패하면 개체는 도주합니다. 식별을 포기하면 정답을 공개하지 않고 정체를 모르는 상태로 탐험을 종료합니다.
- 정체를 모르는 상태에서 포획을 시도할 수는 없습니다. 이름을 정확히 맞힌 경우에만 포획 판정을 진행합니다.
- 포획에 성공한 개체는 즉시 로스터와 저장 데이터에 추가됩니다. 영입 결과에서 타입·초기 우호도·직무를 확인하고 `새 동료 보기`로 배틀 상세를 열 수 있습니다.
- 완공된 적합 시설에 자리가 있으면 영입 결과의 `배치 준비`에서 동료와 직무를 선택한 상태로 생산량을 미리 볼 수 있습니다. 배치 버튼을 눌렀을 때 기존 비용이 적용됩니다.

### 포켓몬 관리

- PC에서 우호도·경험치·시설 특수능력과 다음 턴 생산량을 확인합니다. `배틀 능력과 장착 기술`에는 현재 HP 상한과 전투 능력치, 장착 기술, 다음에 편성되는 공격기가 표시됩니다.
- 행복의알을 장착하면 PC의 사탕 사용 버튼 위에 사탕 한 개당 받는 경험치가 표시됩니다.
- 도구를 만들 수 있으면 본거지 자원 버튼에 제작 가능 수가 표시됩니다. 자원의 `지닌 도구`에서 다음 턴에 받을 부품을 확인할 수 있습니다.
- 동료가 네 마리 이상이면 PC에서 이름이나 타입으로 찾을 수 있습니다. 검색하는 동안에는 선택한 동료가 유지됩니다.
- 같은 이름의 포켓몬을 여러 마리 보유하면 PC·엔트리·시설 배치·도구 장착·배틀 교체·전선 파견에서 번호와 레벨로 구분할 수 있습니다.
- 음식과 회복 아이템은 우호도를 최대 15 회복하고, 사탕은 기본 경험치 20을 지급합니다. 재고가 부족하거나 우호도·특수능력이 이미 상한이면 해당 소비를 할 수 없습니다.
- 기술머신은 특수능력을 5 올리며 최대치는 100입니다.
- 전투 엔트리는 최대 6마리이며 확장할 수 없습니다. 6마리가 등록된 상태에서는 다른 포켓몬을 등록하려면 기존 엔트리를 먼저 해제해야 합니다.
- 엔트리 편성 화면에서 포켓몬을 클릭하거나 슬롯으로 드래그해 등록합니다. 슬롯에서 순서를 바꾸고 해제할 수 있습니다.
- 엔트리 1번 슬롯이 선봉입니다. 포켓몬이 쓰러지면 생존한 엔트리에서 다음 포켓몬을 고릅니다.
- 부품 3개로 지닌도구를 제작하고 포켓몬에게 장착할 수 있습니다.
- 상점의 에너지 충전권은 자금 5로 행동력을 최대 2 회복합니다. 이미 최대 행동력이면 구매할 수 없습니다.
- 다음 턴마다 기본 우호도가 2 감소합니다. `먹다남은음식`과 `평온의방울`은 이 감소에 영향을 줍니다.
- 개체별 우호도 하한에 닿으면 턴 종료에 경고합니다. 다음 턴에도 하한이면 이탈합니다. 본거지에서 경고까지 5턴 이내인 포켓몬을 확인하고 PC에서 음식이나 회복 아이템을 줄 수 있습니다.
- 이탈 경고가 뜬 동료에게 줄 음식이나 회복 아이템이 있고 행동력이 모자라면 PC에서 바로 충전권을 살 수 있습니다. 충전 뒤 선택한 동료에게 사용할 아이템을 직접 누릅니다.
- 우호도 관리에서 다른 동료가 다음 턴에 이탈할 예정이면 회복 버튼 근처의 `다음 이탈 예정`으로 대상을 바꿀 수 있습니다.
- 기합의띠는 장착한 동안 이탈을 막고 소모되지 않습니다. 이탈한 포켓몬은 직무와 전투 엔트리에서 빠지며, 지닌도구는 보관함으로 돌아가고 도감 기록은 남습니다.

### 트레이너와 우호도 성향

- 새 게임을 시작하면 주요 트레이너 목록에서 플레이어의 트레이너를 무작위로 결정합니다.
- 처음에는 숲 공터의 세 흔적에서 타입·키·몸무게를 살펴 동료를 고릅니다. 마우스와 키보드는 단서를 확인한 위치에서 클릭 또는 Enter로, 터치는 같은 위치를 한 번 더 눌러 영입합니다. 세 마리를 모두 영입하면 트레이너를 공개합니다.
- 트레이너의 `pokemon`에 포함된 진화 계열은 인연 포켓몬으로 판정하고 초기 우호도에 10을 더합니다.
- 인연 포켓몬이 아니면서 `specialtyTypes`와 타입이 일치하면 초기 우호도에 5를 더합니다.
- 인연 포켓몬 보너스와 선호 타입 보너스는 중첩하지 않으며, 둘 다 해당하면 인연 포켓몬의 +10만 적용합니다.
- 트레이너의 포켓몬 목록은 우호도 판정용이며, 해당 포켓몬을 처음부터 소유하거나 엔트리에 지급하지 않습니다.
- 전설·환상 포켓몬도 동일하게 우호도 인연만 나타내며 자동으로 지급되지 않습니다.

고사리 그늘, 이끼 길목, 나무뿌리 곁의 기척을 살피면 동료 수첩에 타입 단서와 키·몸무게가 적힙니다. 영입한 포켓몬의 이름과 초상은 영입 순간 드러나고 수첩에 초상이 남습니다. 3마리를 고르면 신분증에서 트레이너의 이름과 선호 타입을 확인합니다.

- 선호 타입은 `{ id, nameKr }` 형태로 저장합니다. 판정에는 `type.json`과 포켓몬 데이터가 공통으로 사용하는 타입 ID를 사용하고, 이름은 JSON 가독성을 위해 함께 둡니다.
- 비선호 타입은 별도 저장하지 않고, 선호 타입의 `relationMap.damageFrom`이 1보다 큰 타입으로 계산합니다.
- 여러 선호 타입을 가진 트레이너는 각 선호 타입의 약점을 합쳐 비선호 타입으로 사용하며, 선호 타입과 겹치면 선호 판정을 우선합니다.
- 관계 판정 우선순위는 `인연 포켓몬 → 선호 타입 → 비선호 타입 → 중립`입니다.

### 월드맵과 배틀

- 처음에는 본거지를 포함한 시작 지역 10곳이 열립니다. 한 지역의 10곳을 모두 확보하면 북서, 남동, 북동 지역이 차례로 열립니다.
- 새 게임의 시작 지역에는 본거지 1곳, 서로 다른 상대 트레이너 6명의 거점, 미점령지 3곳이 있습니다. 플레이어는 상대 후보에서 제외되며 서남 거점은 미점령지입니다.
- 시작 지역은 인접 거점을 정찰한 뒤 도전할 수 있습니다. 새로 개방하는 후속 지역에는 대표 거점 하나와 외곽 거점 두 곳을 가진 세력이 둘씩 배치됩니다. 후속 지역은 개방 후 원하는 순서로 도전할 수 있으며, 정찰하면 거점 담당자와 세력 소속을 확인할 수 있습니다. 도전에는 행동력 2와 전투 엔트리가 필요하고 승리한 거점 한 곳을 확보합니다.
- 도전할 수 있는 거점의 기록에서 `엔트리 편성`을 열어 등록 인원과 출전 순서를 바꿀 수 있습니다. 일반 공격기가 없는 포켓몬에는 현재 상태를 알리고, 이후 일반 공격기를 장착할 수 있으면 기술명과 레벨도 표시합니다. 창을 닫으면 같은 거점에서 도전할 수 있습니다.
- 정찰에서 PC를 열면 선택한 상대 타입과 육성 대상이 이어집니다. 새 기술이나 다음 레벨에서 피해가 늘어나는 경우 필요한 사탕과 행동력, 예상 피해 변화를 확인할 수 있습니다.
- 정찰의 `상성·교대 분석`에서 편성된 동료의 피해와 유효 PP를 비교하고 선봉을 바꿀 수 있습니다.
- 정찰의 `상성·교대 분석`에서 선택한 상대 타입에게 피해를 줄 수 있는 미편성 동료의 기술·피해·유효 PP를 확인합니다. 각 동료의 육성 전망을 열거나 편성 창으로 이동할 수 있습니다.
- 첫 도전은 Lv.2 캐터피가 상대입니다. 첫 승리 보상은 자금 5와 경험치 사탕 1입니다. 시작 지역에서 확보한 거점은 본거지 외 한 곳당 턴마다 자금 3을 지급합니다.
- 후속 지역의 거점은 확보한 연결선을 따라 본거지까지 이어질 때 턴마다 자금 3을 지급합니다. 고립된 거점은 자금 지급이 멈추고 턴마다 충성도가 35 떨어집니다. 충성도가 0이면 미점령지가 됩니다. 경로를 복구하면 다음 턴부터 지급이 재개되고 충성도가 35씩 최대 100까지 회복됩니다. 지도에는 보급로와 고립 거점이 표시됩니다.
- 보급로를 위해 추가 점령이 필요하면 정찰 기록에서 최소 행동력과 현재 잔량을 확인할 수 있습니다. 본거지의 `보급로 보기`는 상실 예정 거점의 기록을 바로 엽니다.
- 다음 턴에 상실할 고립 거점은 본거지의 턴 진행 버튼 아래에서 확인할 수 있습니다. 배틀 중 다른 엔트리로 유효 공격을 쓸 수 있으면 교체를 안내합니다. 유효 공격 수단을 모두 잃었다면 이미 쓴 행동력 2를 돌려받지 않고 기권할 수 있습니다.
- 기술 카드에 현재 상대에게 명중했을 때의 피해를 표시합니다. 위력·명중률·상성·남은 PP도 함께 확인할 수 있습니다.
- 교체 후보마다 현재 상대를 공격할 기술 한 개와 명중 피해, 남은 PP를 보여 줍니다.
- 기술 버튼 위에서 직전 라운드의 행동 순서와 피해·빗나감·무효, 능력치 하락이나 흡수 회복 같은 후속 효과를 확인합니다. 현재 능력치 단계는 양쪽 포켓몬의 HP 아래에 표시됩니다.
- 독·맹독·화상·마비·잠듦·얼음은 배틀에서 포켓몬의 체력이나 행동에 영향을 줍니다. 치료소에서 생산한 치료 아이템은 살아 있는 선봉의 상태이상을 없앱니다. 이 조작은 배틀 한 라운드를 사용하며, 상대는 치료 후 행동합니다.
- 진화형의 원본 Lv.1 기술을 같은 버전의 진화 전 종도 배우면 해당 단계의 습득 레벨을 적용합니다. 보정으로 일반 공격을 잃으면 진화 전 종의 기본 공격을 우선 이어받습니다. 실제 배틀·PC·정찰·대응 탐색에 같은 기술 편성을 씁니다.
- 지역 개방 후 5턴마다 적 트레이너의 수비 레벨이 1씩 최대 3까지 높아집니다. 첫 도전과 미점령지는 기존 레벨을 따릅니다. 정찰에서 수비 레벨과 다음 강화 시점을 확인할 수 있습니다.
- 시작 지역에는 적 한 마리, 새로 개방한 후속 지역에는 적 두 마리가 출전합니다. 기존 저장에서 이미 열린 지역의 점유와 정찰 상태를 복원합니다.

### 도감과 엔딩

- 스타팅과 포획 성공 시 도감에 종을 기록합니다. 같은 종을 여러 마리 보유해도 한 종으로 세며, 현재 로스터와 별도로 저장합니다.
- 본거지의 `목표·도감`에서 지역 확보와 10·25·50종 보상을 확인합니다. 지역 40곳과 도감 25종을 채우면 엔딩에서 계속 플레이하거나 새 게임을 선택할 수 있습니다.
- 본거지의 `설정`에서 `데이터 초기화`를 선택하고 확인하면 이 브라우저의 진행 기록을 지우고 스타팅 선택부터 다시 시작합니다.
- 기존 v1~v3 저장이 있으면 건물·포켓몬·자원·거점을 복원합니다. 손상된 기록은 안내 화면을 통해 다시 읽거나 초기화할 수 있습니다.

## 실행

```bash
npm install
npm run dev
```

개발 서버는 기본적으로 `http://127.0.0.1:5175`에서 실행됩니다.

## 검증

```bash
npm run build
npm run test:unit
npm run test:smoke
npm run test:base-smoke
npm run test:map-smoke
npm run test:later-regions
npm run test:campaign
npm run test:early-campaign
```

- `build`: TypeScript 검사와 Vite 프로덕션 번들 생성
- `test:unit`: Vitest로 게임 규칙·reducer·저장 스키마·React 컴포넌트 검증
- `test:smoke`: 실제 Chrome에서 건설·개척과 저장 복원, 시작 지역의 배틀, 도감 보상, 엔딩 조작과 저장 복구를 검증
- `test:base-smoke`: 빌드된 게임에서 새 게임과 v1 저장의 건설·생산·성장·개척을 키보드와 터치로 검증
- `test:map-smoke`: 빌드된 게임에서 새 배치, v3 배치 복원, 정찰·배틀·점령과 키보드 및 터치 지도 조작을 검증
- `test:later-regions`는 Chrome에서 후속 세력 공개, 자유 도전, 보급 재연결, 고립 3턴 후 상실과 저장 복원을 검증합니다.
- `test:campaign`은 Chrome의 새 게임 세 개에서 훈련소 생산·성장으로 거점 40곳을 확보하고, 지역별 전투·턴·보급 기록과 새로고침 복원을 확인합니다.
- `test:early-campaign`: 빌드된 게임에서 고정 시드 5개로 서로 다른 트레이너·스타팅 조합의 첫 승리, 저장 상한과 복원, 사탕 성장·충전권 구매 후 두 번째 도전을 검증

## 기술 구성

- React
- TypeScript
- Vite
- Zod 저장 데이터 검증
- Vitest + React Testing Library
- Playwright 스모크 테스트
- 브라우저 `localStorage` 저장

## 주요 구조

```text
src/
  App.tsx                 # 데이터 로드와 화면 라우팅
  domain/                 # 공용 타입과 순수 게임 규칙
  game/                   # GameProvider, reducer, 상태 마이그레이션
  screens/                # 드래프트·본거지·사냥·지도·배틀 React 화면
  services/               # 데이터와 저장소 접근
tests/
  smoke.mjs               # 전체 핵심 흐름 브라우저 테스트
assets/                   # 배경과 건물 이미지
data/                     # 포켓몬·타입·기술·특성 데이터
```

현재 개발 순서와 확정된 게임 규칙은 `PLAN.md`를 기준으로 합니다.
